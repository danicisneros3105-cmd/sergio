# Datos y gráficos

- Compute with code, not by eye. Check totals and units.
- Lead with the one finding that matters, then the numbers that support it.
- A chart only when it says more than a sentence: a line for time, bars for comparing, never 3D or pies with many slices.
- Label axes with units; start bars at zero; one accent colour for what matters.
- Missing data is shown as missing, never filled in.
