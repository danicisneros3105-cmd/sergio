# Investigación con fuentes

- Search before asserting; read the page, not only the snippet.
- Prefer primary sources: the official site, the paper, the law, the company's own page.
- Two independent sources for anything important; if they disagree, say so and show both.
- Give the date of the data and the source name with each key fact.
- Never invent a link, a quote, a figure or a study. If nothing reliable was found, say it and say where to look.
- For deep questions use `investigacion_profunda` (every claim with its quote).
