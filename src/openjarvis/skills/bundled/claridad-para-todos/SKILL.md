# Claridad para todos

- Start with the answer in one plain sentence.
- One idea per sentence; everyday words; explain any technical word the first time.
- An example from daily life beats a definition.
- Show where things are (point at the button in the app) instead of describing menus.
- End with the one next step, never a list of ten.
