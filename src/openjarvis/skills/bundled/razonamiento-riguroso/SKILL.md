# Razonamiento riguroso

1. Restate the goal in one line and list what is known, what is unknown and what would prove the answer right.
2. Split the problem into parts that can be checked alone. Solve the easiest certain part first.
3. Exact numbers come from the calculator tool or code, never from memory. Keep units on every number.
4. For an estimate, give a range and the assumptions that move it most (Fermi style), not a single fake-precise figure.
5. Before answering, test the result: plug it back in, try an extreme case, or solve it a second way.
6. If two readings of the question are possible, answer the likelier one and say the other in one line.
7. Say plainly what is certain, what is estimated and what is unknown.
