nombre: Integraciones bajo control
claves: mcp, cli, api, clave, token, conexion, conectar, integracion
---
- Agrega API propias solo con plan Dev o superior; usa la ruta que comprueba la licencia.
- Nunca escribas claves en memoria del Node, comandos, archivos de trabajo o auditorías.
- Descubre herramientas MCP antes de usarlas y revisa nombre y argumentos exactos.
- CLI ejecuta listas de argumentos sin shell; no instala programas automáticamente.
- Una autorización vence, solo sirve una vez y deja de servir si cambian argumentos o conexión.
- El proceso tiene límites de tiempo y salida; no equivale a una máquina virtual.
