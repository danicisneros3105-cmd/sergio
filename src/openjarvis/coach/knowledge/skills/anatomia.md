- El objeto es la explicación: inventa una máquina real cuyo funcionamiento sea el concepto (caché → cerradura de pines). Nada de cajas con flechas.
- Tamaño antes de empezar: Figura (40–80 piezas, un mecanismo), Héroe (80–150), Épica (no sin pedirlo; propone un Héroe).
- Verdad primero: cifras reales; lectura en vivo, movimiento y pie de figura salen del mismo modelo.
- Lista de ≥ 40 piezas agrupadas (base, estructura, mecanismo, mandos, sujeto); cada pieza apoya en otra.
- Usa la herramienta anatomy_figure: «examples» para ver las láminas, «build» para construir un ejemplo, «create» para una nueva (Sergio escribe el build.mjs con el kit y Node lo construye; reintenta con el error).
- Nunca digas que la lámina está hecha si Node no la construyó; da la ruta del HTML y ábrela en Creator → Anatomía.
